## 1. 概述

在前端提供替换式脱敏的交互入口与词池配置能力。

## 2. 功能点

1. **脱敏模式选择**：任务创建/文档处理时可选「打码（现状）」或「替换」，支持按文档覆盖全局默认值；
2. **词池管理页面**：
   - 按实体类型维护默认词池（人名、公司、地址、证件号等）；
   - 支持自定义添加/删除/批量导入替换词；
   - 支持指定「原词 → 替换词」的精确映射；
3. **映射确认（可选增强）**：替换执行前展示「实体 → 替换词」映射表，允许用户手工调整个别替换词（如统一化名）；
4. **结果预览**：导出前可预览替换后的文档效果（沿用现有预览能力）。

## 3. 依赖与排期

- 后端引擎见 #7；联调依赖 #8 的导出能力；UI 可先行按接口契约开发。
