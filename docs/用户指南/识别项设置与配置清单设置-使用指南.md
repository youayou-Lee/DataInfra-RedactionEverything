# 识别项设置与配置清单设置 · 使用指南

> **这份指南解决一个问题：如何让系统按您的要求决定"查什么、不查什么"。**
> 典型需求：时间不打码但出生日期要打码、某类信息不想每次手动取消勾选、只在特定案件里查某类信息——本文都有对应操作。
> 适用于 2026-09 起（preview2.0.0，含「识别项账号级启停」功能）。

---

## 一、先花 30 秒：系统是怎么决定"查什么"的

系统里有三个东西在共同起作用，**必须放在一起理解**：

```
 识别项设置                配置清单设置                处理文件时
┌──────────────┐      ┌──────────────────┐      ┌──────────────┐
│  识别项(字典) │  →   │  识别清单(选字典) │  →   │  按选中的查   │
│ 系统认识哪些词│      │ 这次带哪本字典    │      │              │
└──────────────┘      └──────────────────┘      └──────────────┘
        │
        └─→ 「纳入默认识别范围」= 不带字典时，兜底那本字典里有没有它
```

| 概念 | 在哪 | 通俗解释 |
|---|---|---|
| **识别项** | 左侧导航 →「识别项设置」 | 系统的**字典**：姓名、身份证号、日期、出生日期、车牌号……每类信息是一个识别项。字典决定了系统"认识"哪些东西 |
| **识别清单** | 左侧导航 →「配置清单设置」 | 一份**勾选好的组合方案**，决定"这一次处理要查哪些类"。系统内置了几份现成清单，您也可以自己建 |
| **默认识别范围** | 不用单独找，它是「识别项设置」里的一个开关 | 您**不选清单、直接上传文件**时，系统按一份看不见的"默认清单"处理。「纳入默认识别范围」开关就是控制某类信息在不在这份默认清单里 |

**一句话记忆：识别项是字典里有什么词，识别清单是这次带哪本字典，纳入默认范围是不带字典时兜底那本里有没有它。**

## 二、识别项设置：两个开关怎么用

打开左侧导航「识别项设置」，确认顶部选中「**文本识别项设置**」标签，就能看到所有识别项卡片。每张系统卡片（带"系统配置"标识）上有两个开关：

### 开关 1：「启用」——允不允许查

- **作用**：控制本账号**允不允许**识别这类信息；
- **关闭后会发生什么**：您账号下的**所有**处理——单次、批量、扫描件、**无论用哪份清单**——都不再识别、不再打码这类信息。这是最强的一档，适合"我这类案件里这类信息根本不用脱敏"的诉求；
- **例子**：关闭「日期」的启用开关后，判决书里的立案日期、开庭时间、签署日期一律不再被打码；
- 关闭后卡片**不会消失**，会灰显并带上「**已停用**」标记，随时可以重新打开。

### 开关 2：「纳入默认识别范围」——不选清单时查不查

- **作用**：在"允许查"的前提下，决定您**不选任何清单直接上传**时，这类信息查不查；
- **只在「启用」开着时有效**；
- **例子**：打开「车牌号」的这个开关后，您日常上传的每份文件都会默认查车牌，不用每次去选清单。

### 三档口诀

| 启用 | 纳入默认范围 | 效果 | 适合谁 |
|:---:|:---:|---|---|
| 关 | —（自动失效） | **禁用**：怎么都不查 | "这类信息我永远不脱敏" |
| 开 | 开 | **常开**：不选清单也默认查 | "这类信息我的案子每份都有，默认查最省事" |
| 开 | 关 | **备用**：平时不查，选了含它的清单才查 | "平时用不上，特定案件才要"（如车牌：合同案不需要、交通事故案才需要） |

### 页面其他操作

- **重置**：点页面右上「重置文本识别项」，恢复系统默认口径（您改过的所有开关都会还原）；
- **新增自定义识别项**：点「新增」，可以教系统认识新的信息类型（如"案卷编号"的特定格式）——这是高级功能，本文不展开；
- 系统识别项的**识别规则本身**（比如日期长什么样）不可修改，您能改的只有上面两个开关。

## 三、配置清单设置：识别清单是什么、怎么用

打开左侧导航「**配置清单设置**」（页面副标题"识别项组合"），这里管理所有识别清单：

- **系统内置清单**：金融服务、法律案卷、医疗记录、政务公开等几份现成方案，可以直接用，也可以复制一份改；
- **自己建**：点新建，给清单起个名字（如"交通事故案"），把需要的识别项勾上（车牌、驾驶证、地址……），保存；
- **处理时怎么选**：单次处理的上传区、批量向导的第一步，都有清单选择处。**选了哪份，就按它勾的查**；
- **不选呢？** 不选清单直接上传时，按「默认识别范围」处理（见上文第二节的开关 2）。

> 小贴士：如果您的案件类型比较固定，建 2-3 份清单按案选用，比每次手动勾选省事得多。

### 处理文件时怎么选清单（重点，别跳过）

以单文件处理为例，正确顺序是：

1. 在单文件处理页**选好文件**（先别急着点开始）；
2. 在**上传区的清单选择处**选好清单——不选的话显示的是「默认清单」（即"默认识别范围"那本兜底字典）；
3. **确认清单无误后，再点开始识别**。

⚠️ **清单在"点开始识别"那一刻就固定了**：当前版本识别开始后（包括中途刷新页面回到结果页）不能更换清单。如果识别完发现清单选错了，请回到上传页重新选清单、重新识别一次。"结果页直接换清单重跑"已列入产品改进计划。


## 四、按需求查：我想……该怎么做

### 场景 1：时间不用打码，但不想每次识别都手动取消勾选

**这是最常见的需求，只需一次设置，永久生效：**

1. 左侧导航 →「识别项设置」→「文本识别项设置」标签；
2. 找到「**日期**」卡片；
3. 关闭「**启用**」开关。

完成。之后单次、批量、扫描件、任何清单都不再识别和打码一般日期（立案日期、开庭时间、签署日期等）。**出生日期是独立的识别项，不受影响，照常打码。**

### 场景 2：只脱敏出生日期，其他日期不管

操作与场景 1 完全相同——「日期」和「出生日期」本来就是两个独立识别项，关闭「日期」即可。

### 场景 3：某类信息平时默认就该查，不想每次选清单

例：做交通事故案的律师，希望车牌号每份文件默认都查。

1. 「识别项设置」→ 找到「车牌号」卡片；
2. 确认「启用」是开的；
3. 打开「**纳入默认识别范围**」开关。

### 场景 4：某类信息只在特定案件里才查

例：车牌号只在交通事故案里查，平时的合同案不用。

1. 「识别项设置」→「车牌号」：确认「启用」开着、「纳入默认识别范围」**关着**（=备用档）；
2. 「配置清单设置」→ 新建一份"交通事故案"清单，勾上车牌号；
3. 处理交通事故案卷时选这份清单，其他案件不选（或选不含车牌的清单）。

### 场景 5：清单里明明勾了某项，却不生效

九成是它在账号级被停用了。识别项清单的编辑页里，被停用的识别项会**灰显并标注「已停用」**，勾选无效。处理办法：去「识别项设置」找到它，把「启用」重新打开。

### 场景 6：改乱了，想恢复系统默认

「识别项设置」→ 点「**重置文本识别项**」→ 确认。所有开关回到系统默认。

### 场景 7：不同案件脱敏口径不一样

为每种案件类型各建一份识别清单（场景 4 的做法），处理时按案选清单；再配合场景 1 的账号级停用处理"永远不需要"的信息。清单管"这次查什么"，账号开关管"永远查/不查什么"，两者配合使用。

## 五、常见问题

| 问题 | 回答 |
|---|---|
| 这些设置只影响我自己吗？ | 是。识别项开关、自建清单都是**账号级**的，同事账号不受影响 |
| 换一台电脑还生效吗？ | 识别项开关：生效（存在服务端您的账号里）。清单选择：部分记忆在浏览器里，换电脑后首次处理时重新选一次即可 |
| 关了「日期」，出生日期还会被打码吗？ | 会。两者是独立识别项，互不影响 |
| 表格里孤零零一个出生日期，会漏吗？ | 有可能。出生日期靠语义识别（依据"出生"等上下文），个别排版特殊的可能漏检，建议成品下载后抽查 |
| 预览/处理页面能改清单吗？ | 当前版本处理前请在**上传页**选好清单；处理中途如需更换，回到上传页重新开始（已列入产品改进计划） |
| 打码和替换（化名）跟这些设置什么关系？ | 识别项/清单决定"**查什么**"，打码方式决定"查到后**怎么处理**"，两件事独立设置 |
| 识别完才发现清单选错了怎么办 | 当前版本请回到上传页重新选清单再识别一次（结果页直接换清单重跑的改进已列入计划） |

## 六、一页速查卡

```
想永久不查某类信息   → 识别项设置 → 关「启用」
想默认多查某类信息   → 识别项设置 → 开「纳入默认识别范围」
想按案件类型换口径   → 配置清单设置 → 建多份清单，处理时选用
清单勾了不生效       → 八成被账号停用了，去识别项设置重新启用
全部恢复默认         → 识别项设置 →「重置文本识别项」
```
