# 律师场景配置指南：仅出生日期脱敏，事件日期不脱敏

> 适用对象：只希望脱敏当事人出生日期、不希望识别打码一般事件时间（立案日期、签署日期、开庭时间等）的账号。
> 设置一次，长期生效，只影响您自己的账号，不影响其他同事。

## 操作步骤（一次，共 1 步）

1. 登录后，点开左侧导航的 **「识别项设置」**；
2. 确认顶部标签在 **「文本识别项设置」**，在卡片列表中找到 **「日期」**；
3. 关闭该卡片上的 **「启用」** 开关。

完成。「日期」卡片会灰显并显示「已停用」标记。

> 说明：**「出生日期」与「日期」是两个独立的识别项**。系统默认就识别出生日期，所以只需停用「日期」这一项，无需其他操作。若您的账号里「出生日期」卡片上的「纳入默认识别范围」开关是关闭状态，请把它打开。

## 设置后的效果

| 处理场景 | 事件日期（开庭时间等） | 出生日期 |
|---|---|---|
| 单次处理（文本件） | 不识别、不打码 | 正常脱敏 |
| 批量处理 | 不识别、不打码 | 正常脱敏 |
| 扫描件 PDF / 图片 | 不识别、不打码 | 正常脱敏 |
| 使用任何识别清单 | 不识别、不打码 | 正常脱敏 |

- 在「识别项组合」编辑识别清单时，「日期」会灰显标注「已停用」，无法勾选；
- 效果仅对本账号生效，同事账号不受影响；
- 如需恢复识别日期，回到识别项设置把「日期」的「启用」打开，或在页面点「重置」恢复系统默认。

## 边界说明（请知悉）

- 停用「日期」后，凡是**没有**明确写着「出生/生日」字样的日期，系统一律不再当作敏感信息处理。极少数排版特殊（如表格中孤立出现的）出生日期，也可能因无法确认语义而漏脱敏，建议成品下载后抽查；
- 本设置只影响「日期」这一类信息；姓名、身份证号、电话等其他类型的脱敏不受影响。
