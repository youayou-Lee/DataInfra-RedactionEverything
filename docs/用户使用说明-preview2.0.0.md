# 数据脱敏工作台 · 用户使用说明

适用版本：preview2.0.0（2026-09-15 上线）　|　面向对象：平台普通用户　|　维护：DataInfra 项目组

> 本工作台用于在分享/汇报文书前，把文档里的姓名、证件号、地址等敏感信息**打码**或**替换成化名**。当前版本请通过**「单次处理」逐个文件**使用；多文件批量能力后续版本开放（见第 6 节）。
>
> 本说明针对 preview2.0.0 的单文件处理流程，面向日常业务用户；系统全部功能（批量、库表、管理员配置等）的总览另见《操作手册》（`docs/操作手册.md`），两份文档不一致处以本说明为准。

---

## 1. 登录

1. 浏览器打开云平台为本系统映射的公网地址（以管理员上线通知为准，形如 `http://<云平台地址>:<端口>`）；
2. 输入管理员开通的账号密码登录；首次登录后建议点页面右上角「修改密码」改掉初始密码；
3. 文件按账号隔离，您上传的文件只有您自己能看到。

## 2. 支持的文件

**以下格式均经过完整端到端实测，可放心使用：**

| 格式 | 打码 | 替换（化名） |
|---|---|---|
| .txt / .md / .html / .htm（纯文本类） | ✅ | ✅ |
| .docx（Word 文档） | ✅ | ✅ |
| .pdf（文本型） | ✅ | ✅ |
| .pdf（扫描型） | ✅ | ❌ 仅打码 |
| .jpg / .jpeg / .png / .bmp / .gif / .webp / .tif / .tiff（图片） | ✅ | ❌ 仅打码 |

**以下格式请勿使用：**

- **.doc**：旧版 Word 格式暂不支持，请先在 Word 里「另存为 .docx」再上传；
- **.rtf**：实测确认脱敏不彻底（成品可能残留敏感信息），**禁止用于正式业务**。

单个文件 ≤ 50 MB。

## 3. 标准流程：单文件脱敏（6 步）

1. **进入「单次处理」**：登录后点左侧导航「单次处理」；
2. **上传文件**：把文件拖进虚线框（或点击选择），上传后**自动开始识别**，等右侧进度结束；
3. **复核识别结果**：右栏列出识别到的敏感项（类型 + 原文），左侧原文中有对应高亮。**确认无误的直接保留；不该处理的点击该项，在弹出小窗里点「移除标注」**；识别遗漏的可在左侧原文中选中文字手动补标；
4. **选择「处理方式」**（见第 4 节）：
   - **打码**（默认）：遮盖敏感内容，可选三种呈现形式；
   - **替换（化名）**：把敏感词换成虚构词，文档保持可读。选这项后请在「化名映射」表里**逐行确认替换词**（见第 5 节）；
5. **点「开始匿名化」**：按钮上会显示本次处理的敏感项数量；
6. **下载成品**：完成后在结果页点「下载文件」；替换模式还会有「**下载化名对照表**」（见 5.3）。点「处理新文件」可开始下一份。

## 4. 两种处理方式怎么选

| | 打码 | 替换（化名） |
|---|---|---|
| 效果 | 敏感内容被遮盖/标签化 | 敏感内容换成同类虚构词，**版式基本保持、文档可读** |
| 适合 | 存档、机器处理、无需阅读内容 | 给领导/其他部门看的汇报版卷宗 |
| 可逆性 | 不可还原 | 不可还原；但可用对照表人工核对 |

**打码的三种形式**（「打码方式」一栏）：

| 形式 | 效果示例 | 适合 |
|---|---|---|
| 结构化标签（推荐） | 陈明飞 → `<姓名[001]>` | 需要明确标记类型、便于后续程序处理 |
| 智能替换 | 陈明飞 → `[人物一]` 这样的类型标签 | 需要类型标记但希望形式更简洁；不提供化名对照表 |
| 掩码替换 | 陈明飞 → 陈** | 快速、直观地隐藏内容 |

## 5. 替换（化名）模式详解

### 5.1 化名映射确认（必做的一步）

选「替换（化名）」后，面板出现**化名映射**表：系统已按默认规则给每个敏感项生成好替换词，您只需要**逐行检查**：

- 每行 = 原文 ｜ 类型 × 次数 ｜ 替换词输入框（可直接修改）；
- **每一行都必须有替换词**——清空某行会导致「开始匿名化」按钮变灰，并提示"请先确认化名映射"；
- 两个不同原文填了**同一个替换词**时，会出现黄色提醒。这只是提醒，不影响执行：如果两个写法（如公司全称/简称）您想统一成同一个词，**填同一个词即可**；
- **执行即按确认的映射**：成品按您确认的替换词逐项替换；个别因排版原因（跨行、词中夹空格）定位不到的位置可能替换不到位，建议下载后抽查一遍成品。

### 5.2 默认化名规则

不修改的情况下，系统按以下规则自动生成替换词：

| 敏感类型 | 原文示例 | 默认替换为 |
|---|---|---|
| 人名 | 陈明飞 | 陈某1（同姓第二人 → 陈某2，依次编号） |
| 人名（无法取姓氏） | 外文名 | 某人1 |
| 公司 | 某某科技有限公司 | 某公司1 |
| 机关单位 | 市公安局 / 县人民法院 | 某公安局1 / 某人民法院1 |
| 银行 | 工商银行某支行 | 某银行1 |
| 地址 | 北京市海淀区中关村大街1号 | 某市某区某街道… |
| 身份证号 | 110101…8515 | 位数正确、校验位合法的虚构号 |
| 手机号 | 13800138000 | 合法号段的虚构号 |
| 银行卡号 | 6222… | 通过卡号校验的虚构号 |

关键保证：**同一原文在全文所有位置都替换为同一个化名**；不同原文各自独立编号，不会两个人共用一个化名。

### 5.3 化名对照表（CSV）

替换模式执行成功后，结果页提供「下载化名对照表」，内容为四列：**原文 / 类型 / 化名 / 出现次数**，Excel 直接打开不乱码。用途：审阅人可借对照表核对脱敏是否到位、必要时人工还原语境。

> ⚠️ 对照表里含**未脱敏的原文**，敏感级别与原件相同，请与原件同等保管，不要随脱敏成品一起外发。

## 6. 当前版本的限制（上线版须知）

| 限制 | 说明 |
|---|---|
| 扫描型 PDF / 图片不支持替换 | 「替换（化名）」入口会标注「扫描件 / 图片暂不可用」，此类文件请用打码 |
| 批量处理（多文件）仅支持打码 | 化名替换的多文件版本（保证跨文件同一人同一化名）在后续版本开放；当前多文件需求建议逐个走「单次处理」 |
| 化名一致性仅限单文件内 | 不同文件之间即使同一人，化名也可能不同，属预期行为 |
| 替换仅对文本类文件生效 | .docx / .txt / .md / .html / 文本型 PDF；扫描型 PDF 与图片请用打码 |

## 7. 实用功能

- **成品水印（可选）**：单次处理右侧「成品水印」输入框（如"仅供XX项目使用"），会在导出的 PDF / 图片成品上叠加半透明平铺水印；留空不添加；
- **现场保持**：单次处理中途切到别的页面或刷新浏览器，**识别与映射结果通常不丢**（超长文档除外），回来即可继续；
- **处理结果页**：左侧导航「处理结果」可回看历史文件、对比原文/成品并重新下载；不再需要的文件可删除（进回收站保留 7 天）。

## 8. 按账号定制识别项（进阶）

系统对每类信息（姓名、身份证号、日期、出生日期……）有统一的默认识别口径。如果您的业务对某些信息有特殊口径，可以在左侧导航「识别项设置 → 文本识别项设置」里按账号调整：

- 每个系统识别项卡片上有两个开关：
  - **启用**：关闭后，您账号下的所有处理（单次、批量、扫描件、任何识别清单）都不再识别该类信息；
  - **纳入默认识别范围**：开启后，即使该类信息默认不识别，也会进入您账号的默认范围（无需每次选择识别清单）。
- 被停用的识别项卡片会灰显并标注「已停用」，随时可重新打开；
- 「系统配置」标识表示该项的识别规则本身不可修改，只能开关；
- 在「识别项组合」编辑清单时，被停用的识别项会灰显标注，无法勾选；
- 想恢复系统默认：在识别项设置页点「重置」即可。

**示例（仅出生日期脱敏、事件日期不脱敏）**：在「文本识别项设置」中找到「日期」，关闭「启用」开关即可。出生日期保持默认开启，不受影响；此后事件发生时间（立案日期、签署日期、开庭时间等）不再被识别和打码。设置一次，长期生效。

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| 忘记密码 / 登录不上 | 联系管理员重置密码或重新开通账号 |
| 「开始匿名化」按钮是灰的 | 替换模式下有行没填替换词——把化名映射表填齐；或敏感项已被全部移除——点「重新识别」恢复 |
| 识别漏了 / 多识别了 | 多识别的点击该项，在弹出小窗点「移除标注」；漏的在左侧原文选中文字手动补标 |
| 某类信息我不想脱敏（如案发时间） | 在「识别项设置 → 文本识别项设置」中关闭该识别项（见第 8 节）；设置对本账号所有处理生效 |
| 想让公司全称和简称换成同一个化名 | 两行的替换词填同一个词即可（黄色提醒可忽略） |
| 扫描件想用化名替换 | 暂不支持，本期请用打码 |
| 成品和预览会不一致吗 | 替换按您确认的映射执行；个别因排版定位不到的位置可能替换不到位，建议下载后抽查一遍成品 |
| 替换会有遗漏吗 | 文本型 PDF 的跨行/夹空格排版可能导致个别词替换不到位（成品仍会生成），下载后请抽查；对脱敏要求高的场景建议改用打码模式 |
| 上传失败 | 检查文件是否为第 2 节支持格式、是否 ≤ 50 MB；扫描型 PDF 识别较慢，请耐心等待 |
| 能传 .doc / .rtf 吗 | .doc 请先在 Word 里「另存为 .docx」；.rtf 实测脱敏不彻底，请勿使用（见第 2 节） |
| 版本确认 | 页面左下角可见版本号与构建时间；当前发布包界面上显示 v1.0.0，对应内部发布标签 preview2.0.0 |
